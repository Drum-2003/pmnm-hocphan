# pmnm-hocphan

Kho bài tập học phần phát triển phần mềm

## Đồ án dự kiến

**Tên đồ án:** Website quản lý thu chi nhóm

**Mô tả:** Xây dựng website hỗ trợ các thành viên trong nhóm
quản lý các khoản thu chi chung. Hệ thống cho phép ghi nhận
khoản tiền đã chi, người thanh toán, số tiền mỗi thành viên
cần đóng góp và theo dõi số tiền còn nợ.
